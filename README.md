# AMATA Team Building 2026

Static website for AMATA Team Building 2026.

## GitHub Pages

Use `index.html` as the main page.

After pushing this folder to GitHub:

1. Open the repository on GitHub.
2. Go to Settings -> Pages.
3. Under "Build and deployment", choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Save.

The site URL will be:

`https://YOUR-GITHUB-USERNAME.github.io/amata-team-building-2026/`
